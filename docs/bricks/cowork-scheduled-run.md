# Schedule a Cowork skill to run unattended

**Tool:** Cowork
**Source status:** Liftable from Agent Academy — Cowork Collective

A skill you run by hand is a demo. A skill that runs on a schedule and drops its result where people already look is infrastructure. This block takes a working Cowork skill and makes it run without you.

## Steps

1. **Pick the skill and the cadence.** Decide which skill to schedule and how often it needs to run — daily, weekly, or on a trigger you define. Match the cadence to the work rhythm: if the thing it checks changes daily, run it daily.

2. **Set up the scheduled run.** Ask Cowork to run the skill on a schedule. Tell it when, and what input to use each time (a folder, a channel, a list — whatever the skill reads). Cowork handles the timer; you define the scope.

3. **Route the output somewhere people already are.** Tell Cowork where to send the result — a chat, a channel, a digest message. The output should land where the people who act on it already look. Do not create a new destination they have to remember to check.

::: warning During the hack, route to somewhere you control
Send it to a chat with yourself, or a channel you created for this exercise. **Not a live team channel, and not an individual colleague.** Automated output arriving unannounced in someone's real workspace is a bad first impression for both you and the tool.
:::

4. **Verify the first unattended run.** Wait for the scheduled time. Confirm the result appeared in the right place with the right content. If it didn't fire, check the schedule and the input path.

5. **Refine the output shape.** The first run will produce too much or too little. Adjust what the skill includes in its routed output — verdicts, top findings, recommended actions — until the message is useful without opening anything else.

6. **Test what happens when input changes.** Add or change an input item and let the next scheduled run pick it up. Confirm the skill handles new material without intervention.

## Apply it to your scenario

> You already have a working skill from an earlier brick. Point the scheduled run at the inputs your scenario cares about — a content folder, a data source, a queue of items to check. Route the digest to a chat or channel your table set up for the exercise. The sentence you want: *"It ran this morning and told us what changed."*
